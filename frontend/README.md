# Scripture Frontend

React, TypeScript, and Vite frontend for the Scripture application.

## Structure

```text
src/
├── api
├── app
├── auth
├── components
├── config
├── hooks
├── pages
├── styles
└── tests
```

The current implementation lives in `src/app` and supports the existing Google sign-in flow.

## Scripts

```sh
npm run dev
npm run build
npm run lint
npm run preview
```

## Environment

Use `frontend/.env.example` as the template for local frontend settings.
